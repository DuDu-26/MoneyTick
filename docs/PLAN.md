# 摸鱼币 MoneyTick：技术方案与路线图

作者：dudu（@DuDu-26）

## 1. 原项目 PayDance 功能清单

PayDance 是 Windows 桌面实时工资看板（Tauri 2 + Vue 3），核心功能：

| 功能 | 说明 | 安卓版状态 |
|---|---|---|
| 实时金额 | 今日入账持续增长，保留 2 位小数；按“每涨 1 分钱”节奏刷新 | ✅ 阶段 1 |
| 薪资模式 | 月薪（÷每月工作天数）/ 日薪 / 时薪（×当天工时） | ✅ 阶段 1 |
| 每周工作日 | 任选周一至周日 | ✅ 阶段 1 |
| 午休剔除 | 午休时间不计薪，状态显示“午休中” | ✅ 阶段 1 |
| 跨零点夜班 | 下班早于上班即夜班，22:00–06:00 显示“正在夜班” | ✅ 阶段 1 |
| 状态与倒计时 | 未到上班 / 正在上班 / 午休中 / 已下班 / 今日休息 / 配置待修正；距离上班、复工、下班 | ✅ 阶段 1 |
| 薪资说明 | 日薪、时薪、分薪、秒薪换算 | ✅ 阶段 1 |
| 迷你悬浮窗 | 只显示金额，可拖拽置顶，透明度 10%–100%，双击回主窗口 | ✅ 阶段 1（并扩展） |
| 货币符号 | 自定义，最多 4 个字符，可留空 | ✅ 阶段 1 |
| 配置校验 | 简洁、可执行的错误提示 | ✅ 阶段 1 |
| 金额滚动动画 | 滚动变换 / 直接变换 | ⏳ 阶段 2（设置已有，动画待做） |
| 首次启动向导 | 三步：薪资模式 → 工作时间 → 偏好 | ⏳ 阶段 2 |
| 亮暗主题 | 跟随系统 / 浅色 / 深色 | ✅ 阶段 1 |
| 中英双语 | 界面全量双语 | ⏳ 阶段 3 |
| 开机自启动 | 桌面托盘常驻 | ⏳ 阶段 3（对应：开机自动恢复悬浮窗） |
| 自动更新 | 后台检查新版本 | ⏳ 阶段 4（检查 GitHub Release） |
| 本地优先 | 无账号、无上传、无遥测 | ✅ 一直保持 |

## 2. 技术方案

- **语言/UI**：Kotlin + Jetpack Compose + Material 3。
- **模块**：
  - `core`：纯 Kotlin。逐行移植 PayDance `src/lib/salary`（工作时段、午休、夜班、校验、快照计算）和货币符号处理，并新增设置模型 `AppSettings` / `FloatConfig`。JUnit 测试覆盖。
  - `app`：Activity（看板、薪资设置、悬浮窗设置、关于）+ `FloatingWindowService`。
- **悬浮窗**：`SYSTEM_ALERT_WINDOW` 权限 + 前台服务（Android 14 起使用 `specialUse` 类型）+ `WindowManager` 的 `TYPE_APPLICATION_OVERLAY` 窗口，内容用 `ComposeView` 绘制。
  - 拖动/缩放用原始屏幕坐标计算，避免窗口移动造成抖动；松手后把位置、尺寸写回设置。
  - 设置页改动通过 `StateFlow` 实时推给悬浮窗，所见即所得（设置页有预览）。
- **存储**：`SharedPreferences` 里存一份 JSON（kotlinx.serialization），带 `schemaVersion`，损坏时回落默认值。
- **构建与发布**：GitHub Actions 每次推送跑测试、打 APK；打 `v*` 标签发布到 Releases。

## 3. 分阶段计划

1. **阶段 1：骨架与核心（本次）**：核心算法 + 测试、看板、薪资设置、可调悬浮窗、CI 打包。
2. **阶段 2：体验打磨**：金额滚动动画、首次启动向导、时间选择器替代手输、悬浮窗贴边吸附、横竖屏/多分辨率适配、正式 App 图标。
3. **阶段 3：系统集成**：开机后自动恢复悬浮窗、通知栏常驻金额、桌面小组件（Glance）、快捷设置磁贴、中英双语。
4. **阶段 4：发布与维护**：正式签名密钥、GitHub Release 检查更新、可能的 F-Droid 上架、Issue/PR 模板。
